Focus Crawler

Privacy Policy

Focus Crawler is a Chrome extension that helps users stay focused by temporarily blocking distracting websites during user-started timed focus sessions.

Effective Date: May 14, 2026 Developer: Jeremy Carlsten Contact: jeremy@jeremycarlsten.com

1. Information Focus Crawler Stores

Focus Crawler stores extension settings locally in your browser using Chrome extension storage. This may include:

  • Focus Run duration settings
  • Pomodoro settings
  • Shiny Portal list, meaning websites you choose to block
  • Safe Room list, meaning websites you choose to allow during Boss Room Mode
  • Blocking mode preferences
  • Personality mode preferences
  • Custom blocked-page messages you choose to enter
  • Current Focus Run state, such as whether a timer is active and when it ends
  • Local focus statistics, such as completed Focus Runs, focus minutes, canceled sessions, and blocked attempts
  • Achievement progress, if achievements are enabled

This information is stored locally in your browser and is used only to provide Focus Crawler’s focus-blocking features.

2. Website Blocking and Browsing Activity

Focus Crawler checks website navigation locally in your browser so it can determine whether a site should be blocked during an active Focus Run.

For example, if you add youtube.com as a Shiny Portal, Focus Crawler uses the site URL locally to decide whether to redirect that page to the extension’s blocked page while your Focus Run is active.

In Boss Room Mode, Focus Crawler may check visited site hostnames locally to determine whether they are on your approved Safe Room list.

Focus Crawler does not collect, sell, transmit, or remotely store your browsing history.

Focus Crawler may store local statistics related to blocking activity, such as the number of blocked attempts or blocked attempts by site, only to support local stats and achievement features inside the extension.

3. How Information Is Used

Focus Crawler uses locally stored information to:

  • Start, display, and end timed Focus Runs
  • Block or redirect websites you configured as Shiny Portals
  • Allow approved Safe Rooms during Boss Room Mode
  • Show the correct blocked-page message based on your selected personality mode
  • Save your extension settings
  • Display local focus statistics and achievements
  • Restore focus state if Chrome restarts or the extension reloads

Focus Crawler does not use your information for advertising, profiling, analytics, or tracking.

4. Information Sharing

Focus Crawler does not sell, rent, share, or transfer user data to third parties.

Focus Crawler does not send your settings, website lists, browsing activity, custom messages, or focus statistics to any remote server.

Focus Crawler does not use third-party analytics services.

Focus Crawler does not create user accounts and does not require sign-in.

5. Remote Code and External Services

Focus Crawler does not use remote code.

All JavaScript, HTML, CSS, JSON response files, and extension assets are packaged with the extension. Focus Crawler does not load scripts from remote servers or CDNs.

6. Data Storage and Removal

Focus Crawler stores data locally in Chrome extension storage.

You can remove Focus Crawler data by:

  • Resetting settings inside the extension, if available
  • Clearing extension storage through Chrome
  • Uninstalling the extension

Uninstalling the extension removes the extension and its locally stored extension data according to Chrome’s extension storage behavior.

7. Permissions

Focus Crawler requests Chrome permissions only to provide its focus-blocking features.

  • Storage: Used to save user settings, focus timers, website lists, custom messages, and local statistics.
  • Alarms: Used to end Focus Runs automatically when the selected timer expires.
  • Declarative Net Request: Used to block or redirect configured websites locally during active Focus Runs.
  • Tabs: Used to update or redirect already-open tabs when a Focus Run starts and to help users return from the blocked page when possible.
  • Host Permissions: Used so Focus Crawler can apply blocking rules to websites during active Focus Runs, including Boss Room Mode, where all sites are blocked except approved Safe Rooms.

8. Children’s Privacy

Focus Crawler is not directed toward children and does not knowingly collect personal information from children.

9. Optional Mature Content

Focus Crawler includes optional personality modes. The Unhinged personality mode may include profanity and dark-comedy messages. This setting affects only the text shown inside the extension and does not change how user data is handled.

10. Chrome Web Store Limited Use Disclosure

Focus Crawler’s use of information received from Chrome extension APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Focus Crawler uses data only to provide or improve its single purpose: helping users stay focused by temporarily blocking distracting websites during timed focus sessions.

Focus Crawler does not transfer user data to third parties except as required by law, security, or a user-authorized action. Focus Crawler does not use user data for advertising, does not sell user data, and does not allow humans to read user data.

11. Changes to This Privacy Policy

This Privacy Policy may be updated from time to time. When changes are made, the effective date at the top of this page will be updated.
